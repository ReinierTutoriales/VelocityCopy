# Code Quality Skill

When this skill is active:

1. Analyze the request or code for real opportunities in performance, simplicity, robustness, and UX.
2. If a technically superior alternative exists, compare options and choose the most solid for production. Explicitly state what was improved and why.
3. Implement the optimal solution (not the fastest to write).
4. Verify it does not break existing tests, architecture contracts, or unsupported engine semantics.
5. Prefer native WinUI / Windows APIs over third-party or generic solutions unless clearly justified.
6. Report what was measured vs. what still needs real Windows validation.

Keep changes focused and measurable against real product behavior.
