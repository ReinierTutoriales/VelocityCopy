# Native UI Skill

When this skill is active:

- Use only native WinUI 3 and Windows APIs that are stable and documented.
- Prefer the latest stable version of relevant controls and patterns.
- Do not introduce third-party UI libraries unless there is a strong, justified reason that native cannot cover.
- Result must be polished: correct states, smooth behavior, accessibility considerations, and consistency with the existing compact VelocityCopy design.
- Respect existing architecture contracts around UI tokens, threading, and visual fidelity.
- After changes, note what requires physical validation on Windows.
