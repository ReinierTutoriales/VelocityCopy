## Copiar archivos debería ser sencillo

VelocityCopy reúne tus copias y movimientos en una ventana moderna, clara y compacta. Puedes seguir el progreso, organizar archivos pendientes y decidir qué hacer cuando necesitas pausar, continuar o cancelar.

Ideal para mover fotos, vídeos, documentos y carpetas sin perder de vista lo que está ocurriendo.

## Lo que puedes hacer

- **Ver el progreso de un vistazo:** archivos transferidos, velocidad y tiempo estimado.
- **Controlar tus transferencias:** pausar, reanudar, saltar archivos o cancelar.
- **Organizar varias tareas:** consultar la cola y guardar listas para más tarde.
- **Resolver conflictos con claridad:** decidir qué hacer cuando un archivo ya existe en el destino.
- **Recuperar trabajo pendiente:** continuar o descartar tareas recuperables tras un cierre.
- **Trabajar desde el Explorador:** copiar y cortar como siempre y, con VelocityCopy abierto en segundo plano, utilizar su integración de pegado en carpetas compatibles.

La integración con el Explorador está pensada para carpetas normales del sistema de archivos. No sustituye todas las funciones de pegado de Windows ni funciona necesariamente en ubicaciones virtuales u otras aplicaciones.

## Descargar e instalar

VelocityCopy está preparado para **Windows 11** y cuenta con instaladores para equipos **x64** y **ARM64**.

1. Abre la página de [**Liberaciones**](https://github.com/ReinierTutoriales/VelocityCopy/releases).
2. Descarga el instalador correspondiente a tu equipo cuando esté publicado.
3. Instálalo y abre VelocityCopy para comenzar.

**Importante:** los instaladores se distribuyen sin firma digital. Windows puede mostrar una advertencia de seguridad; comprueba que el archivo procede de este repositorio. La versión 1.3.0 está preparada en el proyecto, pero no debe considerarse publicada hasta que aparezca en Liberaciones.
